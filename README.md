## 🔥 Battle Royale — Graphics Edition v2.0 (Featured)

Fortnite-style HUD layout with ANSI colors and ASCII minimap!

### HUD Layout
1. *Top-left:* Kill counter, Alive count, Turn timer
2. *Top-right:* ASCII minimap (15x15 grid) with player, enemies & zone
3. *Bottom-left:* Player name box
4. *Bottom-center:* Health bar (green/yellow/red) + Armor bar (blue)
5. *Bottom-right:* Inventory slots with weapon rarity + Items (potions/bandages)
6. *Center:* Combat feed, eliminations, nearest enemy info

### Visual Features
1. ANSI color codes throughout
2. ASCII minimap with zone visualization
3. Colored HP/Armor bars with block characters
4. Weapon rarity colors (white/green/cyan/purple/gold)
5. Box-drawing borders
6. Elimination feed with skull marker

### Gameplay
1. 50-player battle royale (you + 49 AI bots)
2. 12 weapons across 5 rarity tiers
3. Shrinking safe zone with increasing damage
4. Loot system — weapons, heals, bandages, armor
5. 3 AI personalities — passive, balanced, aggressive
6. Headshot mechanic, kill feed, rank system

### How to Run
```bash
g++ projects/battle_royale_gfx.cpp -o brgfx
./brgfx
```
